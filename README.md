# Maruthi Eats

Maruthi Eats is a premium food delivery application designed to provide a seamless and high-quality ordering experience. Built with a modern technical stack and a refined design aesthetic, it bridges the gap between convenience and luxury dining.

## 🚀 Key Features

### 🔐 Smart Authentication
*   **Secure Phone Login**: One-time password (OTP) verification for secure user access.
*   **Onboarding**: Intuitive profile setup flow for new customers.

### 🍱 Dynamic Dashboard
*   **Real-time Categories**: Category grid managed directly from Firestore with custom sorting support.
*   **Interactive Banners**: Branded promotional carousel to showcase daily deals and specials.
*   **Quick Access**: One-tap navigation to the full restaurant menu.

### 🍛 Advanced Menu System
*   **Live Pricing**: Automatic synchronization with Firestore ensures users always see the latest prices.
*   **Promotional Support**: Built-in logic for `has_discount` and `discount_price` with professional strikethrough UI.
*   **Dietary Indicators**: Clear visual markers for Vegetarian and Non-Vegetarian items.

### 🛒 Seamless Shopping Experience
*   **Global Cart**: A floating, badged cart button accessible from any screen in the app.
*   **Live Data Sync**: Items in the cart automatically reflect price changes or discount updates in real-time.
*   **Unified Checkout**: Simplified single-page checkout flow with multiple payment options (UPI & COD).

### 📍 Intelligent Address Management
*   **Google Maps Integration**: Precision location picking with an interactive map interface.
*   **Recipient Details**: Ability to save specific names and contact numbers for different locations.
*   **Smart Labels**: Quick selection chips for **Home**, **Work**, and custom labels.
*   **Web Optimized**: Platform-aware logic that ensures stability across Android, iOS, and Web.

### 🚚 Real-time Order Tracking
*   **Animated Feedback**: Status-specific GIFs (Preparing, Out for Delivery, etc.) provide engaging visual updates.
*   **Progress Stepper**: A professional multi-stage tracker showing the exact journey of your meal.
*   **Global Tracker Card**: A persistent tracking card on the home dashboard for active orders.

## 📱 Progressive Web App (PWA)

The application is fully optimized for web deployment, specifically targeting iOS Safari users:
*   **Full-screen Experience**: Meta tags configured to remove browser UI when "Added to Home Screen."
*   **Safe Status Bar**: Seamless integration with the iPhone notch using `black-translucent` styling.
*   **High-Resolution Icons**: Branded apple-touch-icons for a native app feel on the springboard.

## 🏗 Setup & Deployment

### Build the Web PWA
```bash
flutter build web --release
```

### Deploy to Firebase
```bash
firebase deploy --only hosting:customer
```
